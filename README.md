# Subastas-Lógica

Proyecto de subastas en Java usando Programación Orientada a Objetos.

## Funcionalidades
- Registro de usuarios (Vendedor, Coleccionista, Moderador)
- Login de usuarios
- Creación de subastas
- Creación de ofertas
- Visualización de datos

## Tecnologías
- Java
- Maven

## Cómo ejecutar
1. Abrir el proyecto en NetBeans
2. Ejecutar la clase Main
